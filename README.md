# ENERGY — сайт школы вожатых

Сайт педагогического отряда ENERGY: лендинг с записью на обучение, личный кабинет с входом через Telegram,
админка с ролями и временными группами, Телеграм-бот для заявок.

**Стек:** FastAPI + SQLite (SQLAlchemy) + Jinja2, бот на aiogram 3, Docker + Caddy (автоматический HTTPS).

## Что есть

- **Главная** со слайдером, блоком о педотряде, форматом потока (2 месяца + обязательный выезд), заявкой и FAQ.
- **Визитка** `/vizitka` — сайт как полноэкранная презентация для ПК.
- **Открытая игротека** — 133 игры из методичек ENERGY, фильтры и поиск.
- **База знаний** — открытые статьи с инфографикой, закрытые материалы, доступ по закрытой ссылке, файлы.
- **Одобрение руководителями** всего, что попадает в общую базу; **оценки от вожатых**.
- **Тесты** по закрытой ссылке с автопроверкой; конструктор тестов; 5 тестов импортированы из Google Форм.
- **Журнал потока**, карточка энерта, **шкала развития**, оценочные листы ENERGY PRO.
- **Конструкторы**: игра, КТД, свечка/огонёк, мероприятие для СВ — с печатью в PDF.
- **Telegram**: вход, заявки с кнопками, Mini App, `/igra`.

## Роли и права

| Роль | По умолчанию может |
|---|---|
| Руководитель | всё |
| Мастер | видеть заявки, закрытую базу, оценочные листы, результаты тестов, конструкторы, игротеку |
| Орг | закрытую базу, добавлять материалы, конструкторы, игротеку |
| СМИ | закрытую базу, новости и фото |
| Старик | закрытую базу, оценочные листы, конструкторы |
| Педсостав (ENERGY PRO) | закрытую базу, конструкторы |
| Энерт | учиться и видеть свою шкалу |

Сверх роли руководитель создаёт **группы** (поток, отряд, команда на мероприятие) с любым набором прав
и сроком действия. Когда срок истекает, права пропадают сами. Права настраиваются в `app/permissions.py`.

Главные админы задаются в `.env` (`SUPERADMIN_IDS`): они всегда руководители, и снять их из админки нельзя.

## Запуск на своём компьютере (Windows)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
# в .env: SITE_URL=http://localhost:8000, DEV_LOGIN=1, SECRET_KEY=любая строка, SUPERADMIN_IDS=1
uvicorn app.main:app --reload
```

Откройте http://localhost:8000. Для входа без Телеграма нажмите на странице `/login` «Войти как тестовый
пользователь» (работает только при `DEV_LOGIN=1`). Чтобы войти руководителем, откройте
http://localhost:8000/auth/dev?tg_id=1&name=Admin.

## Запуск на VPS

1. Направьте домен (A-запись) на IP сервера. Установите Docker.
2. Создайте бота в @BotFather, затем `/setdomain` → ваш домен (без этого вход через Telegram не заработает).
3. Скопируйте проект на сервер, сделайте `cp .env.example .env` и заполните его. `DEV_LOGIN=0`!
4. Добавьте бота в чат организаторов, запустите его и напишите в чате `/chatid`, затем впишите id в `LEADS_CHAT_ID`.
5. `docker compose up -d --build`

База лежит в `./data/energy.db`. Бэкап — это копия этого файла.

## Структура

```
app/
  main.py          — приложение, подключение разделов
  config.py        — настройки из .env
  db.py            — модели: User, Group, Lead
  permissions.py   — роли и права
  progress.py      — шкала развития (блоки, веса, уровни)
  telegram.py      — проверка входа через Telegram, уведомления о заявках
  routes/          — public (главная, заявка, robots, sitemap), auth, cabinet, admin
  templates/       — страницы
  static/          — css, js, картинки
bot.py             — Телеграм-бот
docs/semantic-core.md — семантическое ядро
```
