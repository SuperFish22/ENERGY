# Семантическое ядро сайта «Школа вожатых ENERGY»

> **Важно.** Частотность здесь не указана: у меня нет доступа к Яндекс Вордстату.
> Перед запуском прогоните запросы через [wordstat.yandex.ru](https://wordstat.yandex.ru) с вашим регионом
> и уберите те, где показов почти нет. Приоритет (★★★ / ★★ / ★) — моя оценка важности для школы, а не частотность.
> Город по умолчанию — Москва (меняется в `.env`: `SITE_CITY`). Если вы в другом городе, замените «москва» во всех запросах.

## Как читать таблицы

- **Интент.** «Учиться» — человек хочет записаться. «Узнать» — ищет информацию (это игротека и база знаний,
  они приводят людей, которые потом идут учиться).
- **Страница.** Куда ведём человека с этого запроса. Страницы со статусом *этап 2–4* появятся позже.

## Что уже сделано на сайте под ядро

- Открытые страницы: главная, `/igroteka` + 134 игры, `/baza` + открытые статьи (2 ждут одобрения).

- `<title>`, `<meta description>`, `<h1>` и тексты главной закрывают кластеры 1–2, частично 3 и 4.
- Разметка Schema.org: EducationalOrganization, Course и FAQPage (вопросы могут показываться прямо в выдаче).
- `robots.txt` закрывает от индексации админку, кабинет, вход и служебные адреса, а для Яндекса склеивает UTM-метки (`Clean-param`).
- `sitemap.xml` собирается автоматически. Новые разделы добавляются в список `PUBLIC_PAGES` в `app/routes/public.py`.

## Что сделать после запуска

1. Добавить сайт в [Яндекс Вебмастер](https://webmaster.yandex.ru) и [Google Search Console](https://search.google.com/search-console), отправить `sitemap.xml`.
2. В Вебмастере указать регион сайта.
3. Подключить Яндекс Метрику. Форма уже отправляет цель `lead`, если на странице есть счётчик и задан `window.YM_ID`.
4. Завести карточку организации в Яндекс Бизнесе (если есть адрес занятий).
